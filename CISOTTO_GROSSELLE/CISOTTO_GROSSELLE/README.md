# `Multiclass_logistic_regression.py`: 
# Implemented first-order optimization algorithms from scratch in Python using NumPy.
# Compared Gradient Descent (GD) with Block Coordinate Gradient Descent (BCGD) using the Gauss-Southwell rule to minimize negative log likelihood on high-dimensional data.
# Evaluated algorithms on synthetic datasets and the real-world ISOLET5 speech recognition dataset.
# Conducted hyperparameter tuning (Grid Search) on Lipschitz constant factors (q) to analyze trade-offs between per-iteration progress and CPU execution time.
